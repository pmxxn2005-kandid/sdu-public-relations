# เว็บไซต์ทดลองบน InfinityFree

โดเมนที่ผู้ใช้เลือก: `sdu-public-relations.rf.gd`
ไฟล์ตั้งค่า: `deploy/infinityfree.env.example`
ยังไม่ได้ตรวจยืนยันการจองชื่อหรือการติดตั้งบนบัญชีของผู้ใช้

1. สมัครที่ https://www.infinityfree.com/ และยืนยันอีเมลด้วยตัวเอง
2. สร้าง hosting account และเลือก free subdomain เช่น sdu-pr.rf.gd หากชื่อว่าง
3. เปิด SSL ให้ชื่อเว็บ แล้วสร้าง MySQL database
4. เก็บข้อมูล FTP และรหัสฐานข้อมูลไว้ส่วนตัว อย่าส่งรหัสผ่านในแชต ส่งเฉพาะชื่อโดเมนและค่าที่ไม่เป็นความลับเพื่อเตรียมไฟล์ตั้งค่า
5. ก่อนย้าย ต้องตรวจบัญชีจริงว่าอนุญาตจัดเก็บ app/storage นอกพื้นที่ public, รองรับ PHP extensions และค่า max_input_vars/upload_max_filesize เท่าใด ยังไม่ยืนยันว่าเว็บปัจจุบันติดตั้งได้โดยไม่ปรับโครงสร้าง
6. ต้องย้าย SQLite ไป MySQL พร้อม ID เดิมและไฟล์รูป งานนี้ยังไม่ได้ดำเนินการ ห้ามรัน seed เพื่อแทนข้อมูลจริง
7. ทดสอบโฟลเดอร์รูป การแนบ 1000 รูป ข่าวลิงก์ภายนอก ดาวน์โหลดรูป และ Admin ก่อนใช้เว็บทดลอง

ตรวจไฟล์ในเครื่อง: รูปประมาณ 290 MB, assets ประมาณ 572 KB, ไม่พบไฟล์เกิน 10 MB (ขณะตรวจ 10 ตุลาคม 2569)

ผู้ให้บริการระบุไฟล์ PHP/HTML สูงสุด 1 MB, .htaccess 10 KB และไฟล์อื่น 10 MB และไม่รองรับการเปลี่ยน PHP settings รายบัญชีตามคำตอบฟอรัม จึงต้องตรวจค่าจริงก่อนย้ายและไม่ถือว่า .user.ini จะมีผลเสมอ
